1. GAME CẦN CODE
==================================================

Tên game: “Bắt Cá Ao Làng”

Màn hình: mobile-first portrait 9:16.

Theme:
Ao làng Việt Nam, ao sen, cầu tre, bèo nước, cá rô, cá chép, cua đồng, tôm, nắng chiều, cute casual, màu nước / giấy dó.

Core gameplay:
Người chơi thả lưới/cần câu xuống ao để bắt cá.

Luồng chơi:
1. Người chơi bấm giữ / tap hold để thả lưới xuống.
2. Lưới đi xuống theo chiều dọc.
3. Khi người chơi thả tay hoặc lưới đạt maxDepth, lưới bắt đầu kéo lên.
4. Trong lúc kéo lên, nếu lưới chạm cá thì bắt cá.
5. Cá bị bắt được thêm vào giỏ/inventory.
6. Khi lưới lên mặt nước, bán toàn bộ cá, cộng tiền.
7. Tiền dùng để nâng cấp:
   - maxDepth
   - netSize
   - pullSpeed
   - capacity
8. Người chơi tiếp tục vòng lặp để bắt cá sâu hơn, nhiều tiền hơn.

Game không cần backend. Game phải playable.

==================================================
6. CORE LOGIC BẮT BUỘC
==================================================

Implement các function chính:

1. createInitialState()
- load localStorage
- set money/bestMoney
- set default upgrades
- spawn fish

2. updateGame(state, input, dt)
- update net state
- update fish movement
- check collision when pulling
- update feedback
- handle result when net reaches top

3. startDrop()
- if net idle, chuyển sang dropping

4. startPull()
- nếu đang dropping thì chuyển sang pulling

5. updateNet()
- dropping: y += dropSpeed * dt
- nếu đạt maxDepth thì pulling
- pulling: y -= pullSpeed * dt
- nếu về mặt nước thì sellCatch

6. checkFishCollision()
- chỉ khi pulling
- distance(net, fish) <= netSize + fish.size
- nếu capacity còn thì catch
- set fish.caught = true
- push vào currentCatch

7. sellCatch()
- total = sum value
- bad item có thể value thấp hoặc penalty nhẹ
- money += total
- sessionEarned += total
- lastCatchValue = total
- clear currentCatch
- save bestMoney
- open result/upgrade UI

8. buyUpgrade(type)
- check đủ tiền
- check maxLevel
- trừ tiền
- tăng level
- apply stat
- save

9. spawnFish()
- spawn theo depth tier
- cá gần mặt nước rẻ
- cá sâu đắt
- cá hiếm ít
- respawn nếu số lượng thấp
